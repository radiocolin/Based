# Project Mandates

## File Protection
- **PROHIBITION:** AI agents are **explicitly forbidden** from modifying `Info.plist`, `.pbxproj`, or any other Xcode project configuration files.
- **WORKFLOW:** If a change to these files is required (e.g., version updates, capability changes), you MUST describe the change to the user and ask them to perform it manually. Do NOT use any tools to automate edits to these files.
